## Diffusion 线补全（commit 0210e2c）
设计成 2×2 矩阵：`latent|pixel` × `flow|reg`，四个 arm 同 DiT-S/同数据/同预算，官方 100 对 Y 指标对标 E11 (33.47)。
`reg` = 确定性残差回归（零初始化输出头），是 flow 的 PSNR 上界探针；`gap(reg − flow@NFE)` = 采样代价。

修掉的坑（都会毁结果）：
1. DiT 写死 `self.grid` → 带 pad 的推理 tile assert 崩；改成 token 数动态推导 + pos_embed 恒 0（分辨率无关）
2. Flux latent 没减 shift 0.1159 → 现在 `(z−shift)*scale`，且 config.json 优先于 preset 表
3. HR 目标 latent 默认 `posterior.sample()` 注入噪声 → 改 `mode()` 为默认
4. 训练 crop ≠ 推理 tile → latent LR256→HR512，pixel LR64→HR128，`--tile` 自动取训练 crop
5. tile 硬切 → 重叠 2×pad 线性交叉淡入（对 torch bicubic 参考 maxdiff=0）
6. 采样无 seed → `sample_flow(seed=)`
7. EMA 0.9999 → 0.999（20k step 量级）
8. pixel 全量评估 8h → tile 批量推理 `--tile-batch 8`（OOM 自动减半），~2h

新增：`--objective {flow,reg}`、`scripts/server/run_diffusion_matrix.sh`（一键全矩阵+评估+汇总表）、
`exp/DIFFUSION_PLAN.md`（含 H1–H5 假设与决策规则）。
