# Orthogonal-Frequency-Regularized Discriminative Regression for Real-World Single-Image Super-Resolution

**RealSR (V3)** · Cai et al., ICCV 2019 — real camera zoom-paired SR. A stride-1 U-Net +
BSRGAN pretraining + orthogonal **wavelet high-frequency loss** (+ shift-ensemble) + **Muon**
optimizer + test-time augmentation.

> **Headline (×2, official `Test.m`, Limited-range Y, no shave, all 100 pairs):**
> **PSNR-Y 34.41 · SSIM 0.9285 · MUSIQ 55.96 · MANIQA 0.3534** at **18.7M** params.
> A training-free decomposition (§4) shows RealSR ×2 fidelity is capped at **≈ 34.4–35.7 dB**
> by bi-lens registration error — we sit at that ceiling.

## 2. Method

- **Backbone**: stride-1 regression U-Net (base 64, mult 1,2,4,4, num-res 2, attn at levels
  2–3), residual-bicubic with a **zero-initialised head** ⇒ step-0 output is exactly bicubic.
  Stride-1 (no lossy downsample in the trunk) is the single biggest lever (+0.38 dB, 3.7×
  fewer params) — real high-frequency survives bicubic and must be reconstructed at full phase.
- **Loss**: L1 + **orthogonal wavelet high-frequency loss** — multi-scale L1 on Haar HL/LH/HH
  subbands (λ≈8), with a **shift-ensemble** variant (average over 4 dyadic offsets ≈ DTCWT
  shift-invariance, our best perceptual increment) and optional db2/db4/DTCWT bases. This is a
  *targeted, zero-inference-cost* regulariser: it stops L1 from smearing recoverable high band.
- **Optimizer**: **Muon** (Newton–Schulz orthogonalised updates on ≥2D weights, AdamW on the
  rest), lr 5e-3 — beats AdamW across the whole lr range; substitutes for a chunk of the
  pretraining gain.
- **Pretraining**: BSRGAN synthetic-degradation pretrain (DIV2K+Flickr2K) → RealSR finetune.
- **TTA**: D4 8-fold self-ensemble (flip/rot) → float mean, inference-only.

## 3. Negative results (all evaluated, all reported honestly)
Diffusion (pixel/latent × flow/reg), **Mamba/VSS** (−2.3 dB at equal budget), coord-injection,
freq-routing, gated FFN, flattened pyramids, D4 equivariance, bijective wavelet U-Net,
**dual-branch wavelet U-Net**, **DTCWT loss**, **frequency-domain rectified flow**, and
**adversarial-degradation data mining (N3)** all failed to beat the recipe above. The consistent
reason (§4): at 390 real pairs, discriminative regression saturates the recoverable signal;
generating the *unpredictable* residual high-band only adds misaligned artefacts.

## 4. The empirical upper bound (training-free, deterministic)
`diffusion/oracle.py` measures the three irreducible MSE components on the 100 GTs directly
(no model, no test-set fitting):

| wall | ×2 measurement |
|---|---|
| **Registration** `E_align` (sub-pixel shift of GT) | 0.2px→41.1 · **0.3px→37.7** · 0.5px→33.4 dB |
| **Band-limit** `E_null` (ideal LPF to LR Nyquist) | 40.65 dB (SSIM 0.979) |
| **Sensor noise** `E_noise` (Donoho wavelet-MAD, σ̂≈0.9/255) | 49.05 dB |

Composite (relative-MSE sum) + a realistic 0.3–0.4 px residual misregistration ⇒ **ceiling ≈
34.4–35.7 dB**. Our **34.41** is inside it. (This *corrects* the folklore "38–40 dB noise
floor": on RealSR the noise is small; **registration** is the binding wall.) Full analysis:
[`exp/RELATED_WORK_AND_UPPER_BOUND.md`](exp/RELATED_WORK_AND_UPPER_BOUND.md); the complete
experiment chronicle: [`exp/FINAL_REPORT.md`](exp/FINAL_REPORT.md).

## 5. Layout / reproduce

```
diffusion/   # stride-1 U-Net + wavelet/Muon/TTA/eval (stage B, primary)
model/       # SwinIR-line code (stage A)
exp/         # FINAL_REPORT.md (chronicle) + RELATED_WORK_AND_UPPER_BOUND.md + notes
data/RealSR(V3)/{Canon,Nikon}/{Train,Test}/{2,3,4}/   *_LR2.png / *_HR.png
```
Requirements: Python 3.10+, PyTorch 2.x, CUDA (4090 48GB for training; 8GB works for eval).

```bash
# train (finetune from a BSRGAN-pretrained ckpt; see exp/FINAL_REPORT.md §6 for the full recipe)
python -m diffusion.train_pixel --data-root "data/RealSR(V3)" --out experiments/run \
  --backbone unet --size S --base 64 --mult 1,2,4,4 --num-res 2 --attn-levels 2,3 --native-lr 0 \
  --objective reg --residual 1 --scale 2 --lr-patch 64 --batch 128 --amp --cache-data 0 \
  --optimizer muon --muon-lr 5e-3 --muon-momentum 0.95 --muon-ns-steps 5 \
  --dwt-loss --dwt-weight 8 --dwt-levels 2 --dwt-shift 4 --ema 0.999 --steps 10000 --init <pretrain.pt>
# evaluate (official protocol + IQA + TTA)
python -m diffusion.eval_official --ckpt experiments/run/ckpt_best.pt --data-root "data/RealSR(V3)" \
  --mode pixel --objective reg --iqa --tta --tile 64 --pad 16
```
